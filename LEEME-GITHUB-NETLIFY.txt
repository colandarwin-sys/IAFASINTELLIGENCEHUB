IAFAS INTELLIGENCE HUB - GITHUB + NETLIFY

1. Descomprime este ZIP.
2. En GitHub abre tu repositorio.
3. Usa Add file > Upload files.
4. Sube TODO EL CONTENIDO que está dentro de esta carpeta, de modo que index.html quede en la raíz del repositorio.
5. Haz Commit changes.
6. En Netlify elige Add new project > Import an existing project > GitHub.
7. Selecciona tu repositorio.
8. Configuración recomendada:
   - Framework: Other / Static
   - Build command: vacío
   - Publish directory: .
9. Pulsa Deploy.

Después, cada actualización que llegue a GitHub podrá publicarse automáticamente en el mismo sitio de Netlify.
