IAFAS INTELLIGENCE HUB v4.2.136

PUBLICACION EN GITHUB
1. Sube TODO el contenido de esta carpeta a la raiz del repositorio.
2. Deben quedar index.html, netlify.toml y la carpeta static/ directamente en la raiz.
3. No subas solamente index.html: el portal necesita static/ y sus archivos de datos.

PUBLICACION EN NETLIFY
- Si Netlify ya esta conectado al repositorio, al actualizar GitHub se generara el nuevo deploy.
- Build command: dejar vacio.
- Publish directory: .
- El archivo netlify.toml ya esta configurado con publish = ".".

CAPACITACIONES
- La base publicada esta en static/capacitaciones-maestro.js/json.
- El Excel maestro esta incluido como MAESTRO-CAPACITACIONES-IAFAS.xlsx.
- Para actualizar el maestro desde Excel y regenerar la base, usar primero abrir-portal-local.cmd y Centro de Fuentes. Luego publicar los archivos actualizados en GitHub/Netlify.
